# 런닝 캘린더 (Marathon Training Calendar)

마라톤 대회 준비용 훈련 캘린더 웹앱입니다.

## 기능
- **캘린더**: 월별로 매일의 훈련 프로그램을 색상(훈련 종류)으로 표시, 완료(✓)/미완료(✗) 한눈에 확인
- **날짜 상세**: 날짜를 누르면 워밍업·본훈련·쿨다운 등 상세 프로그램 확인
- **기록**: 완료/미완료/예정 체크, 실제 거리·시간(평균 페이스 자동 계산)·평균 심박·체감 강도(RPE)
- **메모**: 실제로 달리며 느낀 점 기록 → '일지·통계' 탭에서 모아보기
- **러닝화**: 훈련마다 신은 러닝화 기록, 러닝화별 누적 거리·교체 권장 거리·러닝 이력 관리, 은퇴 처리
- **목표 대회 여러 개**: 대회명·날짜·종목(풀/하프/10km/5km/기타)·목표 기록·우선순위(A/B/C) 관리, 가장 가까운 대회 D-day 표시, 캘린더에 대회 일정 자동 추가
- 목표 기록 기반 훈련 페이스 계산, 선택한 대회 기준 3주 테이퍼링 계획 자동 생성
- **통계·그래프**: 주간(계획 대비 완료·평균 페이스), 월간(거리·횟수), 훈련별(인터벌·조깅·템포·LSD 등 거리 비중·평균 페이스·심박) - Chart.js
- **가민 이미지로 기록 입력**: 공유 이미지를 올리면 OCR(Tesseract.js)로 날짜·거리·시간·페이스·심박 자동 인식 → 확인 후 저장, 이미지는 Supabase Storage(비공개)에 보관
- **상세 화면 이미지**: 날짜별 훈련 카드에서 기록 이미지 썸네일·크게 보기·삭제
- **백업**: JSON 내보내기/불러오기

## 구조
- 정적 사이트 (빌드 없음): `index.html`, `style.css`, `app.js`(UI), `store.js`(데이터), `plan.js`(훈련 종류/페이스/계획)
- 데이터: Supabase (로그인 + RLS로 본인 데이터만 접근). `config.js`가 비어 있으면 localStorage 로컬 모드
- 배포: Vercel (GitHub 저장소 연결, push 시 자동 배포)

## Supabase 설정
1. 프로젝트 생성 후 SQL Editor에서 `schema.sql` 실행
2. Project Settings > API 의 URL, anon(publishable) 키를 `config.js`에 입력
3. Authentication > URL Configuration 의 Site URL을 Vercel 주소로 설정

## 참고
기본 훈련 계획의 페이스는 목표 기록으로 추정한 값입니다. 현재 주간 거리·컨디션·통증 여부에 맞게 조정해서 사용하세요.
